# 🤖 Telegram Live Multi-Account Manager Bot (A to Z Guide)

এই টেলিগ্রাম বটটির সাহায্যে আপনি আপনার যেকোনো সংখ্যক আসল টেলিগ্রাম অ্যাকাউন্ট (IDs) এক জায়গায় সংরক্ষণ করে রাখতে পারবেন এবং যেকোনো সময় এক ক্লিকে সেগুলোকে আপনার বা যেকোনো গ্রুপের **Live Stream / Voice Chat**-এ আসল শ্রোতা হিসেবে যুক্ত করতে পারবেন।

---

## 📋 বটটি চালু করতে যা যা লাগবে (Requirements):

| আইটেম | কোথা থেকে পাবেন? | বিবরণ |
|---|---|---|
| **১. BOT_TOKEN** | [@BotFather](https://t.me/BotFather) | টেলিগ্রাম অ্যাপে `@BotFather` এ গিয়ে `/newbot` লিখে একটি বট তৈরি করুন এবং প্রাপ্ত টোকেনটি নিন। |
| **২. API_ID & API_HASH** | [my.telegram.org](https://my.telegram.org) | ব্রাউজারে `my.telegram.org`-এ গিয়ে আপনার যেকোনো একটি টেলিগ্রাম নম্বর দিয়ে লগইন করে "API development tools"-এ ক্লিক করে API ID ও HASH বানিয়ে নিন। |
| **৩. ADMIN_ID** | [@userinfobot](https://t.me/userinfobot) | আপনার নিজের টেলিগ্রাম নিউমেরিক আইডি (যাতে অন্য কেউ আপনার বট নিয়ন্ত্রণ করতে না পারে)। |
| **৪. আপনার টেলিগ্রাম অ্যাকাউন্টসমূহ** | আপনার ফোন নম্বরগুলো | যে অ্যাকাউন্টগুলো আপনি লাইভে ঢুকাতে চান, সেগুলোর ফোন নম্বর। |

## ⚙️ সার্ভার বা পিসিতে রান করার সহজ নিয়ম:

### ধাপ ১: ফাইল ক্লোন বা ডাউনলোড
আপনার VPS (Ubuntu/Debian) বা কম্পিউটারে ফাইলগুলো রাখুন:
```bash
cd telegram_bot
```

### ধাপ ২: কনফিগারেশন সেট করুন (.env)
`.env.example` ফাইলটিকে রিনেম করে `.env` করুন এবং মানগুলো বসিয়ে দিন:
```bash
cp .env.example .env
nano .env
```
ভেতরে এই তথ্যগুলো দিন:
```env
BOT_TOKEN=7123456789:AAEjklmnopqrsTUVWXYZ123456789
API_ID=28491023
API_HASH=b871c89012345678abcdef0123456789
ADMIN_IDS=123456789
DATABASE_FILE=sessions.json
JOIN_DELAY_SEC=2.5
```

### ধাপ ৩: ১-ক্লিকে বট রান করুন
```bash
chmod +x deploy.sh
./deploy.sh
```
অথবা ম্যানুয়ালি:
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python3 bot.py
```

## 🎯 টেলিগ্রামের ভেতরে কীভাবে ব্যবহার করবেন:

1. আপনার তৈরি করা বটে যান এবং `/start` দিন।
2. **`➕ নতুন অ্যাকাউন্ট যোগ করুন`** বাটনে চাপ দিন।
3. আপনার যে আইডি যোগ করতে চান তার ফোন নম্বর লিখুন (যেমন: `+8801700000000`)।
4. টেলিগ্রামে আসা ৫ সংখ্যার কোডটি বটে মেসেজ করুন।
5. ব্যস! অ্যাকাউন্টটি নিরাপদে সেভ হয়ে যাবে। এভাবে যত ইচ্ছা অ্যাকাউন্ট যোগ করুন।
6. যখন লাইভে যাবেন, বটে এসে **`🚀 লাইভ স্ট্রিমে জয়েন করান`** বাটনে চাপুন এবং আপনার লাইভের লিংক দিন।
7. সব আইডি স্বয়ংক্রিয়ভাবে লাইভ স্ট্রিমে আসল ইউজারের মতো যোগ হয়ে যাবে!
8. **`❤️ লাইভে রিঅ্যাকশন পাঠান`** দিয়ে লাইভে লাভ, ফায়ার, তালি রিঅ্যাকশন দিতে পারবেন।
9. লাইভ শেষ হলে **`🛑 লাইভ ত্যাগ করুন`** চাপলে সব আইডি সাথে সাথে বেরিয়ে আসবে।
